Identity Provider (eID / AusweisApp / BundID)

      
    
        
  • eID (Personalausweis, NFC/PIN via AusweisApp): nur über verifizierten eID-Server/Dienst gemäß BSI-Vorgaben; Transaktions-/State/Nonce-Validierung, kein PIN/CAN/Chipdaten-Speicher.
    • 
        
  • BundID: separater Adapter, Aktivierung erst nach offizieller Machbarkeits-/Zugangsprüfung (kein fiktiver OAuth-Flow, keine Simulation).
    • 
        
  • Account-Linking: explizite Besitzverifikation, keine automatische Verknüpfung nur per E-Mail; Kunden- vs. Mitarbeiter-Domäne getrennt.
    • 
        
  • Stufen: L1 Passwort, L2 Passwort+MFA, L3 staatliche eID (Step-up für kritische Aktionen).
    •
